# Seed

Planning input for this repository, written before any lesson exists.

| File | What it is |
|---|---|
| [`curriculum/`](curriculum/README.md) | The curriculum outline: 36 module cards with required, recommended and optional topics per role, the design of the common session and its workshop, and a resource list |
| [`suggestions.md`](suggestions.md) | Improvements, adjacent topics and follow-up sessions, each with where it lands and how soon it is worth doing |

The outline is in English. The lessons, handouts and slides built from it are written in Canadian French.

Start with the [curriculum index](curriculum/README.md).
