# Knowledge

Curated facts worth keeping across sessions: facts that cannot be found by looking at the repository and that would otherwise be rediscovered or forgotten.

## Rules

- **One topic per file:** `claude-code.md`, `environment.md`, and new topics as needed.
- **Format:** each fact is one bullet that starts with the date it was checked. It ends with its source: a URL, a command, or "observed" for something seen in a session.
- **Belongs here:** verified behaviour of tools, the state of the environment, confirmed usage rules with their sources.
- **Elsewhere:** decisions (go in `decisions/`), work status (goes in `state.md`), and anything the repository already shows.
- **Never here:** secrets, personal data, details of a particular machine (operating system, installed versions, security settings, other devices), conversation transcripts.
- **Pruning:** when a fact is found to be stale, replace it with the new dated fact, or delete it if nothing replaces it.
