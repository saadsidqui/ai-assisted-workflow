# C-03 · Task fit and limits

- **Where it sits:** Common core
- **Who:** Everyone: required
- **Delivery:** Core session, segment 2
- **Time:** 6 min

The most valuable beginner skill is choosing what to hand over. People who start with the wrong task conclude that the tool is useless or, worse, trust it where they should not.

## Outcomes

A participant can:

- Classify a task as a good fit, a poor fit or high-stakes.
- Apply a five-question test before delegating.
- Explain why expertise matters more with AI, not less.

## Topics

### Required

- Good fits: drafting, rewriting, summarizing material you provide, changing format, extracting structure, explaining, generating options, first-pass analysis, code assistance.
- Poor fits: facts with no source to check against, output that must be right without review, results you cannot judge yourself, decisions that belong to a person.
- High-stakes: anything about people (hiring, evaluation), money, legal commitments, production systems, client deliverables. These need approved tools and stronger review.
- The five-question fit test: is it worth it (value), what happens if it is wrong (risk), can I undo it (reversibility), what data does it need (sensitivity), can I check the result and how long will that take (verifiability).
- "AI can help with this" is a different statement from "AI should decide this".
- You can only delegate what you can evaluate.

### Recommended

- The uneven frontier: excellent at some hard-looking tasks and poor at some easy-looking ones. Test on a real example instead of assuming.
- Honest time accounting: time saved minus time spent reviewing and fixing.
- Where to start: frequent, low-risk, easy-to-verify tasks.

### Optional

- A team task inventory and opportunity scoring workshop.
- Choosing a first pilot.

## Checkpoint

> Three tasks on screen. Vote green, yellow or red for each, then one volunteer explains the yellow.

## Practice

Participants write down one task from their own week for each colour. They reuse the green one in the workshop.

## Presenter notes

- Pick the three example tasks so the room disagrees on at least one. The disagreement is the lesson.
