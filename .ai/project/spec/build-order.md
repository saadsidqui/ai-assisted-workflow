# Build order

The order that makes each deliverable usable by the next. It extends the order in [R-03](curriculum/resources/R-03-asset-backlog.md) with the build tooling, the fictional engagement and the textbooks. The definitions of done are in [`deliverables.md`](deliverables.md).

1. **Build tooling and skills.** These come from initialization, Phase 3: the `publish` skill, `tools/`, fonts.
2. **Glossary (R-02).** Every lesson depends on its terms.
3. **Fictional engagement brief.** It supplies the running example of the common session and the material of every workshop pack. This step is an addition to R-03, which lists the brief as an asset but gives it no place in the order.
4. **Core lessons, C-01 to C-08**, with full speaker notes. The X-02 lesson is written alongside them, because segment 4 of the common session uses one of its slides.
   - **Then further reading (R-01),** before step 5, so that the further-reading section of each core lesson can link to it. This is an addition to R-03, which does not place R-01 in its order.
5. **Presenter guide (S-01) and workshop packs (S-02).** The author tests the packs with the real tool and account type.
6. **Core handouts:** working loop, brief skeleton, review checklist, "what goes where" template.
7. **Common-session deck**, on demand.
8. **Core textbook**, on demand.
9. **Track lessons.** Start with the track the author names (OD-09).
10. **Overlays X-01 and X-03.** The organization's privacy lead reviews the X-02 policy pack before its first delivery.
11. **Track handouts, workshop versions and labs** for each track, in the same order as step 9.
12. **Track decks**, on demand.
13. **Track textbooks**, on demand, each after its track's lessons and overlays.

Before each delivery, whatever the step: refresh the landscape snapshot (C-02), work through the "re-verify" lists of the lessons in use, and open every link.
