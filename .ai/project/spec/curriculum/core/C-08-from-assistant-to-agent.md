# C-08 · From assistant to agent

- **Where it sits:** Common core
- **Who:** Everyone: required
- **Delivery:** Core session, segment 6 (short); full version in tracks
- **Time:** 3 min in session, 15 min full

Agents are how AI-assisted work is done today, not an advanced topic. Everyone needs the plain-language version, because the difference between an assistant that answers and an agent that acts changes what supervision means.

## Outcomes

A participant can:

- Explain the difference between an assistant and an agent.
- Say what they would want an agent to ask before acting.
- Recognize the typical ways an agent goes wrong.

## Topics

### Required

- An assistant answers. An agent acts: it plans, uses tools, looks at the result and repeats until it is done or stuck.
- What changes for you: you hand over an outcome, then review both the result and how it was reached.
- More autonomy needs clearer limits on what it may read, change, run and send.
- The loop and the gates stay the same: brief well, verify, approve.

### Recommended

- One example per track: a coding agent making a change, a research agent producing a cited brief, an agent operating a browser or an office application.
- Supervision patterns: approve each step, approve a plan and then review the result, or let it run inside an isolated environment.
- Typical failures: a confident wrong turn, doing more than was asked, reporting "done" when it is not, following instructions planted in content it read.
- Background, long-running and scheduled work.

### Optional

- Several agents working together.
- Connectors and MCP.
- Skills.
- Computer and browser use.

## Checkpoint

> What would you want an agent to ask you before it does this on your behalf?

## Presenter notes

- Keep it to one short recorded clip of an agent working. This segment is a preview of the track sessions, not a lesson.
